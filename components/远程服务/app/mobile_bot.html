后续指令

手机连接

手机与电脑连接同一 Wi-Fi，或使用 Tailscale。首次配对后可添加到手机主屏幕，之后从主屏幕进入；重启接收器通常无需重新扫码。

连接自检

只读检查手机到电脑的连接。不发送任务，不消耗模型额度。

电脑端结果仅供参考：Tailscale 已连接不代表手机已连通；发现 Codex 程序也不代表已登录或额度充足。自检不会自动重试、切换地址或打开 Codex。

脱敏摘要

连接不上电脑时

  • 确认电脑已开机，接收窗口仍在运行。
  • 确认手机和电脑的 Tailscale 都已连接，当前主屏幕使用 100.x 开头的入口。
  • 也可以让手机和电脑连接同一 Wi-Fi，改用配对页里的局域网链接。
  • 切换 Wi-Fi 或移动网络后稍等片刻，再点“重新检查”。
  • 若提示授权失效，请从电脑重新配对并打开新链接，不要只当作网络离线。

额度与余额

电脑当前Codex登录账号的共享额度，非本会话单独额度；不是现金余额。查询不发送任务。

额度由电脑端 Codex 登录状态决定，可能使用 30 秒缓存；不会自动轮询，重置时间按手机本地时间显示。

当前 Harness 使用的 DeepSeek 官方 API Key 账户余额，不是 Codex 额度。

按币种分别显示总余额，赠送与充值余额仅作补充；查询不提交模型任务，可能复用 30 秒缓存，不会自动轮询。
